## Recurring portions in a single meal

**Pick ONE protein anchor**, then add the supporting items. Calories/protein are approximate.

| Component (per 1 person, 1 meal) | Typical portion | ~Calories | ~Protein |
|----------------------------------|-----------------|-----------|----------|
| **Protein anchor — choose one:** |                 |           |          |
| • Moong sprouts / legumes (cooked)| 150 g          | 150       | 11 g     |
| • Paneer (pan-grilled)           | 80–100 g        | 230       | 16 g     |
| • Eggs                           | 2 eggs (100 g)  | 145       | 12 g     |
| • Chicken (cooked)               | 120 g           | 200       | 30 g     |
| **Always add these:**            |                 |           |          |
| Sautéed non-starchy veg          | 150 g           | 90        | 4 g      |
| Raw salad (kachumber or leafy)   | 150 g           | 45        | 2 g      |
| Curd / buttermilk                | 120–200 ml      | 70        | 6 g      |
| Mixed nuts                       | 15 g            | 95        | 3 g      |
| Mixed seeds                      | 10 g            | 55        | 2 g      |
| Cooking fat (ghee/oil)           | 5 g (1 tsp)     | 45        | 0 g      |
| **Optional add-ons:**            |                 |           |          |
| Cheela / thalipeeth              | 1 piece         | 110       | 5 g      |
| Green soup                       | 200 ml          | 60        | 2 g      |
| Hummus                           | 40 g            | 70        | 3 g      |

!!! info "Typical single-plate total"
    Roughly **450–600 kcal** with **30–45 g protein** — the sweet spot for a low-calorie, high-protein meal. Numbers are estimates for planning, not a clinical prescription.
